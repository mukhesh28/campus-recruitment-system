# Campus Recruitment System

A simple web application to manage campus recruitment: students, colleges, companies, jobs and placements.

## Features
- Admin login / logout
- Add, edit, delete and search Students, Colleges, Companies, Jobs, Placements
- Dashboard with record counts

## Technologies Used
- Python (Flask)
- SQLite database
- HTML and CSS

## How to Run
1. Install Python from python.org
2. Open a terminal in this folder and run: `pip install -r requirements.txt`
3. Run: `python app.py`
4. Open http://127.0.0.1:5000 in your browser
5. Login with username `admin` and password `admin123`
